# The Book of Answers

A simple and mystic web app inspired by "The Book of Answers". Focus on your question, and open the book to receive guidance.

## Deployment

This project is hosted on Vercel.

### Staging / Preview
To create a preview deployment, run:
```bash
vercel
```

### Production
To deploy to the production environment, run:
```bash
vercel --prod
```

## Features
- Multi-language support (13 languages)
- PWA (Progressive Web App) ready
- Social share card generation via Canvas
- Minimalist and mysterious aesthetic
